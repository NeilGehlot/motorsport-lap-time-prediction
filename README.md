# Motorsport Lap-Time Prediction

A student project exploring lap-time prediction using motorsport data.

I started this project to get more comfortable with working with racing data, feature engineering, regression models, and model evaluation. The project has two parts: a Formula 1 analysis using real race data and a small synthetic WEC dataset to explore the same idea in an endurance-racing setting.

## What I Did

The project has two main parts:

- Formula 1 analysis using real race data
- WEC analysis using a synthetic dataset

For both parts, I compared Linear Regression and Random Forest and looked at how well they could predict lap times.

---

## Formula 1

For the F1 part, I used data from the **2023 Bahrain Grand Prix** through FastF1.

The features used for prediction are:

- Lap number
- Stint lap
- Recent average lap time
- Tyre compound
- Driver

The target variable is **lap time in seconds**.

### Data Preparation

Before training the models, I cleaned the lap data by removing:

- Pit-in laps
- Pit-out laps
- Non-green-flag laps
- Laps without a recorded lap time

I also created additional features, including the lap number within a stint and a rolling average of recent lap times.

Driver and tyre compound are categorical variables, so I converted them into numerical features using one-hot encoding.

### Models

I compared two models.

**Linear Regression**

I used Linear Regression as a simple and interpretable baseline.

**Random Forest**

I used Random Forest as a second model because it can capture more complicated and nonlinear relationships between the features.

The models were evaluated using:

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)

### Validation

I first used a random train-test split as a baseline.

I then used a chronological split, where earlier laps are used for training and later laps are used for testing. This makes more sense for race data because a real prediction system would be trying to predict future laps rather than randomly selected laps from the same race.

### Additional Analysis

After making predictions, I looked at the residuals to understand where the models were making mistakes.

The analysis includes:

- Comparing Linear Regression and Random Forest residuals
- Random Forest feature importance
- Prediction consistency between drivers
- Prediction errors during the later part of a stint

## WEC

The WEC section was built separately as a small experiment.

I did not have real WEC telemetry available for this project, so I created a **synthetic dataset** representing two Hypercar entries with three drivers per car over a 300-lap race.

The simulated lap times include:

- Base lap pace
- Stint progression
- Driver variation
- Night racing
- Multiple drivers
- Multiple stints

The purpose of this section is to see whether the same general modelling approach can be explored in an endurance-racing setting.

The WEC data is **not real WEC telemetry** and should not be interpreted as real team or driver performance data.

The same general approach is used here:

- Linear Regression
- Random Forest
- MAE and RMSE
- Residual analysis
- Driver consistency
- Late-stint error analysis


The FastF1 cache and generated output files are kept out of the repository.

## Running the Project

### 1. Clone the repository

```bash
git clone <repository-url>
cd motorsport-lap-time-prediction
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

On Windows:

```powershell
venv\Scripts\activate
```

### 3. Install the dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the F1 analysis

```bash
python src/f1_prediction.py
```

The first run may take a little longer because FastF1 needs to download the race data. The data is cached locally so it does not need to be downloaded every time.

### 5. Run the WEC analysis

```bash
python src/wec_prediction.py
```

The WEC dataset is generated by the script, so no separate dataset is required.

## Limitations

This is an exploratory project rather than a finished racing prediction system.

The F1 model currently uses only one race, the 2023 Bahrain Grand Prix. Because of that, the results should not be treated as representative of Formula 1 as a whole.

The WEC dataset is synthetic, so it should not be interpreted as real WEC performance data.

There is also a limitation with the current rolling-average feature. The way it is currently calculated can include information from the lap being predicted. For a proper real-time prediction model, this should be changed so that the feature only uses information from previous laps.

If I continue developing the project, I would first fix this issue and then test the approach across multiple races. I would also make sure that every feature used for prediction only contains information that would actually have been available at that point in the race.

## What I Learned

The main thing I got from this project was experience working with motorsport data rather than just using a prepared machine-learning dataset.

I also got a better understanding of why the way data is split matters. A random train-test split is easy to use, but it is not always appropriate for sequential data like racing. Looking at chronological validation and residuals helped me think more about how the model would actually be used.

The project also gave me more practice with feature engineering, regression models, and understanding model errors instead of only looking at a single accuracy number.
